# SubBridge

[English](README.md) · **Русский**

Серверный конвертер зашифрованных подписок.

SubBridge загружает подписку с настраиваемым профилем устройства v2rayTun,
расшифровывает её содержимое и выдаёт стандартные ссылки через постоянный URL.
Результат можно использовать напрямую в клиенте или добавить в подписки выбранных
пользователей 3x-ui. Сервис запускается одним бинарным файлом на Go со встроенной веб-панелью.

## Возможности

- **Несколько источников** — до 32 подписок с отдельными кешами и HWID,
  общей выгрузкой и просмотром конфигов с группировкой по подпискам.
- **Преобразование подписок** — зашифрованные ссылки v2rayTun, Happ, Xray JSON/JSONC,
  списки URI и подписки в Base64.
- **Выгрузка конфигов** — VLESS, VMess, Trojan, Shadowsocks, SOCKS/HTTP и Hysteria 2;
  скачивание всех конфигураций или только VLESS.
- **Профили устройств** — сохранённый автоматический HWID или заданный вручную
  идентификатор, настройка заголовков и ограниченное число попыток HWID.
- **Интеграция с 3x-ui** — передача выбранных конфигов через API или добавление ссылки подписки
  с сохранением существующих внешних ссылок и настроек пользователей.
  Клиенты и инбаунды загружаются из панели и выбираются в списках с поиском и сортировкой.
  Отдельное окно позволяет выбрать конкретные конфиги или целые подписки источников.
- **Веб-управление** — русский и английский интерфейс, отдельные настройки панели,
  выбор IP и порта, формирование команды SSH-туннеля.
- **Управление сервисом** — установщики и консольные меню для Linux и Windows,
  обновление, автозапуск и кеш, сохраняющийся при сбоях источника и перезапусках.

## Быстрый старт

На Linux скачайте и запустите установщик. Он выберет архив для вашего процессора
и проверит его контрольную сумму:

```bash
curl -fL https://raw.githubusercontent.com/MrTeeett/subbridge/main/install.sh -o install.sh
sudo bash install.sh
sudo subbridge credentials
```

Для установки сборки разработки из обновляемого релиза `dev` выполните
`sudo bash install.sh -dev`. Дальнейшие обновления через консоль сохраняют выбранный канал.
Если в новом репозитории ещё нет стабильного релиза, используйте `-dev` после
первой успешной [сборки Actions](https://github.com/MrTeeett/subbridge/actions).

По умолчанию веб-панель доступна на `http://127.0.0.1:8780/admin/`.
Подключитесь через SSH-туннель, войдите в панель и добавьте источник подписки.
Команда туннеля описана в разделе [первого подключения](docs/README.ru.md#web-panel),
а Windows и другие способы установки — в разделе [установки](docs/README.ru.md#installation).

После установки команда `subbridge` открывает консольное меню.

## Поддерживаемые платформы

| Платформа | Архитектуры | Управление сервисом |
| --- | --- | --- |
| Linux | `amd64`, `arm64`, `armv7`, `386` | systemd или OpenRC |
| Windows | `amd64`, `arm64` | Планировщик заданий |

Бинарники Linux собраны статически. Для запуска конвертера на целевой машине
не нужны Go, Node.js, подключённый телефон или отдельная установка Xray.
Для интеграции с 3x-ui нужен её штатный API внешних подписок клиентов.
Внешние узлы подключаются напрямую к провайдеру и не становятся локальными инбаундами Xray.

## Разработка

Проект использует **Go 1.26** и стандартную библиотеку; отдельной сборки фронтенда нет.
Сборка, тесты и упаковка запускаются скриптами проекта с жёстким лимитом памяти ОС
4 ГиБ и без параллельных заданий.
Команды и выпуск релизов через GitHub Actions описаны в разделе [разработки](docs/README.ru.md#development).
